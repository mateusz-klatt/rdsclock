# rdsclock 2.0.0 — EN / PL / FR

## English

rdsclock 2.0.0 brings English, Polish and French to all three operator
interfaces: terminal (Textual), browser and desktop (Tkinter). Use
`--lang en`, `--lang pl` or `--lang fr` with `--tui`, `--web` or `--gui`.
English remains the default. Controls, columns, status messages and the
operator log share one translation catalog; broadcast PS, PI and CT values
and receiver JSONL field names retain their original meaning.

The dashboards introduced in 1.1.0 show per-station Clock-Time, source
agreement, outliers and the difference from the host clock. **WIDE** captures
N stations simultaneously when they fit within one SDR passband, then decodes
the channels from that capture. **HOP** visits stations sequentially across
the FM band. The panels refresh as decoded results arrive; WIDE does not
receive the entire 87.5–108 MHz band at once.

This release also fixes a display cache bug: CT received without a confirmed
PI can no longer overwrite the saved time of a confirmed station. Publication
now tests the tagged source and installed wheel, prepares a GitHub draft with
verified assets, publishes the same files to PyPI, and only then publishes the
GitHub release. Existing files must have matching SHA-256 hashes.

1.1.0 remains available. Its PyPI publication succeeded; the missing GitHub
assets have been restored from the original PyPI files. No published history
or tags were rewritten.

## Polski

rdsclock 2.0.0 udostępnia język polski, angielski i francuski we wszystkich
trzech interfejsach: terminalowym (Textual), przeglądarkowym i desktopowym
(Tkinter). Dodaj `--lang pl`, `--lang en` lub `--lang fr` do polecenia z
`--tui`, `--web` albo `--gui`. Domyślny pozostaje angielski. Przyciski,
kolumny, statusy i dziennik korzystają ze wspólnego katalogu tłumaczeń;
nazwy stacji PS, identyfikatory PI, dane CT i nazwy pól JSONL nie są tłumaczone.

Panele wprowadzone w 1.1.0 pokazują czas CT poszczególnych stacji, zgodność
źródeł, obserwacje odstające i różnicę względem zegara komputera. **WIDE**
odbiera N stacji jednocześnie, jeśli mieszczą się w paśmie jednego odbiornika
SDR, a następnie dekoduje kanały ze wspólnego zapisu. **HOP** kolejno odwiedza
stacje w paśmie FM. Widoki aktualizują się w miarę otrzymywania wyników;
WIDE nie odbiera jednocześnie całego pasma 87,5–108 MHz.

Poprawiono również pamięć ostatniego CT w panelach: obserwacja bez
potwierdzonego PI nie nadpisuje już czasu zapamiętanego nadajnika. Proces
wydawania testuje kod z tagu i zainstalowaną paczkę, tworzy szkic wydania
GitHub ze sprawdzonymi załącznikami, publikuje te same pliki na PyPI i dopiero
wtedy udostępnia wydanie GitHub. Istniejące pliki muszą mieć zgodne sumy SHA-256.

Wersja 1.1.0 pozostaje dostępna. Publikacja na PyPI powiodła się; brakujące
załączniki GitHub uzupełniono oryginalnymi plikami z PyPI. Historia i tagi
opublikowanych wersji nie zostały przepisane.

## Français

rdsclock 2.0.0 propose l’anglais, le polonais et le français dans ses trois
interfaces : terminal (Textual), navigateur et bureau (Tkinter). Ajoutez
`--lang fr`, `--lang en` ou `--lang pl` à une commande utilisant `--tui`,
`--web` ou `--gui`. L’anglais reste la langue par défaut. Les commandes,
colonnes, états et messages du journal partagent un catalogue de traduction ;
les noms PS, identifiants PI, données CT et noms des champs JSONL sont conservés.

Les tableaux de bord introduits en 1.1.0 affichent l’heure CT de chaque station,
la concordance entre les sources, les valeurs aberrantes et l’écart avec l’horloge
de l’hôte. **WIDE** reçoit N stations simultanément lorsqu’elles tiennent dans
la bande passante d’un seul SDR, puis décode les canaux de cette capture
commune. **HOP** passe successivement d’une station à l’autre dans la bande FM.
L’affichage s’actualise à mesure que les résultats arrivent ; WIDE ne reçoit
pas toute la bande 87,5–108 MHz simultanément.

Cette version corrige aussi le cache CT des interfaces : une observation sans
PI confirmé ne peut plus remplacer l’heure mémorisée d’une station identifiée.
La publication teste désormais le code étiqueté et le paquet installé, prépare
un brouillon GitHub avec les fichiers vérifiés, publie ces mêmes fichiers sur
PyPI, puis rend la version GitHub publique. Les fichiers existants doivent
avoir les mêmes empreintes SHA-256.

La version 1.1.0 reste disponible. Sa publication sur PyPI avait réussi ; les
fichiers manquants sur GitHub ont été restaurés depuis les originaux PyPI.
L’historique et les tags déjà publiés n’ont pas été réécrits.

## Install / Instalacja / Installation

Python 3.12+ on Linux. Tk support is needed for `--gui`; the `tui` extra is
needed for `--tui`. Browser mode has no additional dependencies.

```bash
python -m pip install --upgrade 'rdsclock[tui]==2.0.0'

# WIDE: simultaneous capture / wspólny odbiór / capture simultanée
rdsclock recon --host 127.0.0.1 --wide 98.3,98.8 --gain 28 --dwell 75 --web --lang pl

# HOP: sequential reception / odbiór kolejny / réception successive
rdsclock recon --host 127.0.0.1 --hop 98.8,102.4,107.5 --gain 28 --dwell 75 --tui --lang fr
```

Use frequencies and gain appropriate to your antenna. Each dashboard owns
one receiver process; launch one per `rtl_tcp` endpoint. The browser defaults
to <http://127.0.0.1:8080/>.

**EN:** Agreement between stations does not prove correct UTC or authenticate
the transmitters. The uncertainty is a model estimate, not a calibrated UTC
error bound. English and French are NATO’s official languages; Polish is the
project’s third language. This independent project is not affiliated with or
endorsed by NATO.

**PL:** Zgodność stacji nie dowodzi poprawności UTC ani autentyczności
nadajników. Niepewność jest oszacowaniem modelu, a nie skalibrowaną granicą błędu
UTC. Angielski i francuski są oficjalnymi językami NATO; polski jest trzecim
językiem projektu. Projekt jest niezależny, nie jest związany z NATO ani przez
nie zatwierdzony.

**FR :** La concordance entre stations ne prouve ni l’exactitude de l’heure UTC ni
l’authenticité des émetteurs. L’incertitude est une estimation du modèle, pas
une borne d’erreur UTC étalonnée. L’anglais et le français sont les langues
officielles de l’OTAN ; le polonais est la troisième langue du projet. Ce
projet indépendant n’est ni affilié à l’OTAN ni approuvé par celle-ci.
