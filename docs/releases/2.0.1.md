# rdsclock 2.0.1 — EN / PL / FR

## English

rdsclock 2.0.1 is a bug-fix release.

- **Consensus:** when the stations split into two equal camps, for example two
  stations an hour ahead of two others, the median fell between them and the
  dashboards showed a time that no station had sent. The time is now reported
  as unavailable and every station is marked as an outlier.
- **Publication:** the release workflow waits for GitHub and PyPI to list new
  drafts and files instead of failing straight away, creates a draft only
  once per run, names any duplicate empty drafts for the operator to delete, and
  marks a release latest only when no newer version is published.

Several Polish stations measured in Warsaw send Clock-Time about one hour
ahead of UTC with a local time offset of zero. rdsclock follows the RDS
standard and reads that field as UTC. Agreement between such stations does not
make the time correct; compare with an independent reference.

## Polski

rdsclock 2.0.1 to wydanie z poprawkami błędów.

- **Konsensus:** gdy stacje dzieliły się na dwie równe grupy, na przykład dwie
  stacje o godzinę przed dwiema innymi, mediana wypadała między nimi i panele
  pokazywały czas, którego nie nadała żadna stacja. Teraz czas jest oznaczany
  jako niedostępny, a wszystkie stacje jako odstające.
- **Publikacja:** proces wydania czeka, aż GitHub i PyPI pokażą nowe wersje
  robocze i pliki, zamiast od razu się przerywać. W jednym przebiegu tworzy
  wersję roboczą tylko raz, podaje identyfikatory pustych duplikatów do usunięcia
  przez operatora i oznacza wydanie jako najnowsze tylko wtedy, gdy nie
  opublikowano nowszej wersji.

Kilka polskich stacji zmierzonych w Warszawie nadaje CT wyprzedzający UTC o około
godzinę, z przesunięciem czasu lokalnego równym zeru. rdsclock trzyma się normy RDS
i odczytuje to pole jako UTC. Zgodność takich stacji nie oznacza poprawnego
czasu; porównaj go z niezależnym źródłem.

## Français

rdsclock 2.0.1 est une version corrective.

- **Consensus :** lorsque les stations se répartissaient en deux groupes égaux,
  par exemple deux stations en avance d’une heure sur deux autres, la médiane
  tombait entre les deux et les tableaux de bord affichaient une heure
  qu’aucune station n’avait émise. L’heure est désormais indiquée comme
  indisponible et toutes les stations sont signalées comme aberrantes.
- **Publication :** le processus de publication attend que GitHub et PyPI
  affichent les nouveaux brouillons et fichiers au lieu d’échouer aussitôt. Il
  ne crée un brouillon qu’une seule fois par exécution, indique les identifiants des
  brouillons vides en double à supprimer par l’opérateur et ne marque une
  version comme la plus récente que si aucune version plus récente n’est
  publiée.

Plusieurs stations polonaises mesurées à Varsovie émettent l’heure CT environ
une heure en avance sur l’UTC, avec un décalage horaire local nul. rdsclock
suit la norme RDS et lit ce champ comme de l’UTC. La concordance entre de
telles stations ne rend pas l’heure exacte ; comparez-la à une référence
indépendante.

python -m pip install --upgrade 'rdsclock[tui]==2.0.1'
